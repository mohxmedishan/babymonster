An AI-powered live news aggregator web application tailored for MONSTIEZ. Built with a dark glassmorphism UI, this app queries live news feeds via secure Vercel serverless functions, featuring advanced client-side sorting and date filtering.

---

## ✨ Features

* **⚡ Serverless RSS Integration:** Bypasses CORS limitations using a secure serverless backend route (`/api/news`).
* **🗂️ Dynamic Sorting:** Sort articles instantly by Latest, Popularity, or Alphabetical Source.
* **📅 Date Filtering:** Filter feeds by All-Time, Today Only, or Past 7 Days.
* **🎨 Dark Glassmorphism UI:** Minimalist, high-contrast interface designed with Tailwind CSS and custom linear glow effects.
* **📱 Responsive Layout:** Optimized for a seamless experience across mobile devices, tablets, and desktops.

---

## 🛠️ Built With

* **Frontend:** HTML5, Tailwind CSS (via CDN), JavaScript (ES6+)
* **Backend:** Vercel Serverless Functions (`api/news.js`)
* **Typography:** `Plus Jakarta Sans` & `JetBrains Mono`
