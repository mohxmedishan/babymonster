An AI-powered live news aggregator web application tailored for MONSTIEZ. Built with a dark, glassmorphism UI, this app queries the **Gemini API** with **Google Search Grounding** to automatically fetch, filter, and summarize the latest positive news, music releases, chart achievements, and world tour announcements for **BABYMONSTER**.

---

## ✨ Features

* **🤖 AI Search Grounding:** Dynamically searches live web sources on page load using Gemini.
* **💖 Good Vibes Only Filter:** Configured strictly to highlight positive achievements, records, and updates.
* **🎨 Dark Glassmorphism UI:** Minimalist, high-contrast interface designed with Tailwind CSS and custom linear glow effects.
* **⚡ Serverless & Lightweight:** Single-file architecture optimized for fast hosting on Cloudflare Pages or GitHub Pages.
* **📱 Responsive Layout:** Designed for a seamless view across mobile devices, tablets, and desktops.

---

## 🛠️ Built With

* **Frontend:** HTML5, Tailwind CSS (via CDN), JavaScript (ES6+)
* **Typography:** `Plus Jakarta Sans` & `JetBrains Mono`
* **API / Grounding Engine:** Google Gemini API (`gemini-2.5-flash` with Google Search tool enabled)
* **Deployment:** GitHub Pages / Cloudflare Pages
